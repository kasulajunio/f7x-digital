## Visão geral

Este repositório reúne a experiência pública do **F7X Digital**, uma frente da Fabio7X voltada a presença digital, páginas de campanha e soluções visuais para projetos que precisam ser claros, acessíveis e fáceis de abrir no navegador.

## Desenvolvimento local

Como o projeto é estático, basta abrir `index.html` em um navegador ou iniciar um servidor local simples. As alterações publicadas na branch principal são disponibilizadas pelo GitHub Pages.
